# 小狐（LTT_GKD）项目目标和输出约束

> 版本：v1.0 | 更新日期：2026-09-15
> 关联文档：[开发文档.md](开发文档.md)

## 一、项目目标

### 1.1 产品定位

小狐是一款基于 Android 无障碍服务的**开屏/弹窗广告自动跳过工具**，无需 Root，通过监听窗口事件自动识别并点击"跳过""关闭"等按钮。

### 1.2 核心目标

| 编号 | 目标 | 验收标准 |
|------|------|----------|
| G1 | **广告自动跳过** | 冷启动带开屏广告的应用，6s 窗口内命中规则并执行点击，成功率 ≥ 80% |
| G2 | **三源规则体系** | 内置（随 APK）+ 本地（用户自建）+ 订阅（Gist/URL 共享）三源可独立加载、合并去重 |
| G3 | **OCR 兜底识别** | 控件树找不到文字时，截图 OCR 识别坐标点击，覆盖纯图片广告 |
| G4 | **规则云端共享** | 用户可上传规则到 GitHub Gist，他人可订阅拉取，去重保留首个创建者版本 |
| G5 | **跳过历史统计** | 记录每次跳过的应用名/时间/匹配文本，提供 7 天趋势图表 |
| G6 | **应用白名单** | 用户可指定应用不执行跳过 |
| G7 | **崩溃自恢复** | 服务进程崩溃后自动重启，非主动关闭时恢复无障碍服务 |
| G8 | **安全优先** | 通用兜底规则仅在开屏窗口（6s）内生效，离开启动阶段不匹配任何文字，杜绝误点 |

### 1.3 非目标（明确排除）

- **不做**需要 Root 权限的功能
- **不做**应用内延迟弹窗广告的自动关闭（安全优先，开屏窗口外不匹配关键词）
- **不做**社区后端服务（使用量 = Gist 订阅数，无独立计数服务）
- **不做**李跳跳/GKD 专用规则格式解析器（统一使用 `RuleSet` JSON 格式）
- **不做**正式签名发布到应用商店（核心开发完成后另行处理）

## 二、输出约束

### 2.1 技术栈约束

| 层 | 约束 |
|----|------|
| 语言 | Kotlin，所有 `.kt` 文件必须包含行级中文注释 |
| UI 框架 | Jetpack Compose + Material3，单 Activity 架构 |
| 异步 | Coroutines + Flow，所有 `launch` 必须使用 `launchSafe` 扩展 |
| 持久化 | DataStore（preferences），实例必须定义在文件顶层（单例） |
| 序列化 | Moshi（`globalAdapter`），规则共享统一使用 `RuleSet` JSON |
| 网络 | OkHttp，实例必须通过 `HttpClientHolder` 单例复用 |
| 加密 | GitHub Token 使用 Android Keystore + AES-GCM 加密，禁止明文存储 |
| 构建 | R8/ProGuard 启用 `isMinifyEnabled=true` + `isShrinkResources=true` |
| SDK | 编译/目标 SDK=34，最低 SDK=26，JDK 17 |

### 2.2 架构约束

| 编号 | 约束 | 说明 |
|------|------|------|
| A1 | package-by-feature | 目录按功能模块组织，不使用 MVC 分层 |
| A2 | 单 Activity | `MainActivity` 承载底部三 Tab（首页/规则/设置），子页全屏覆盖切换 |
| A3 | RuleRepository 全局单例 | `App.repo` 全局唯一，界面/服务/Worker 共用 |
| A4 | DataStore 单实例 | 每个文件仅允许一个 DataStore 委托，定义在文件顶层 |
| A5 | 规则文件目录分离 | local → `filesDir/rules/local/`，subscribed → `filesDir/rules/subscribed/`，built-in → `assets/rules/` |
| A6 | 内置规则过滤 | 仅显示 packageName 在已安装应用列表中或空 packageName（通用兜底）的规则 |
| A7 | 崩溃保护 | `App.setupCrashHandler()` 全局异常捕获，非主线程异常吞掉不崩溃 |

### 2.3 规则约束

| 编号 | 约束 | 说明 |
|------|------|------|
| R1 | 规则模板 | 必须遵循预定义场景（SPLASH/POPUP/Banner/激励视频/通用兜底） |
| R2 | SPLASH 规则 | priority=100, throttleMs=5000, match.type=TEXT, action.type=CLICK_NODE |
| R3 | POPUP 规则 | priority=80, throttleMs=3000, match.type=DESC, action.type=CLICK_NODE |
| R4 | Banner 规则 | priority=60, throttleMs=3000, match.type=DESC |
| R5 | 规则关键词 | 跳过类：["跳过", "跳过广告", "Skip"]；关闭类：["关闭", "关闭广告", "不再提示/不再显示/不感兴趣"] |
| R6 | 上传去重 | 上传前检查同 ID 规则，已存在且作者不同则拒绝，提示"只保留第一个创建者的版本" |
| R7 | 规则编辑器校验 | 必须校验 ID/名称/包名格式/匹配文本/ViewID，校验失败 Toast 提示 |
| R8 | 匹配精度护栏 | 字面量匹配长度上限 16 字符；单字符关键词要求整段精确相等 |
| R9 | 冒泡护栏 | 可点击目标宽占屏 ≥0.85 且高占屏 ≥0.35 时拒绝点击 |
| R10 | 自我短路 | `WindowEventProcessor` 不处理本应用（`com.ltt.gkd`）自身窗口事件 |

### 2.4 服务约束

| 编号 | 约束 | 说明 |
|------|------|------|
| S1 | 开屏窗口 | 所有关键词规则（TEXT/DESC/OCR）仅在开屏 6s 窗口内生效，ID 精确规则不受限 |
| S2 | 跳过后停用 | 成功跳过后 `skippedThisLaunch=true`，立即关闭关键词匹配 |
| S3 | 节流 | RuleEngine 按 throttleMs 节流，null throttleMap 条目视为"未触发" |
| S4 | OCR 节流 | 按包名节流 + in-flight 去重，一次 OCR 未完成不发起新截图 |
| S5 | 协程取消 | `CancellationException` 不当错误处理，向上重抛 |
| S6 | 事件快照 | 回调中同步取 `event.packageName/className`，避免异步使用已回收事件 |
| S7 | Toast 主线程 | `Toast.makeText` 必须在主线程，用 `runOnUiThread` 或 `withContext(Dispatchers.Main)` 包裹 |

### 2.5 订阅约束

| 编号 | 约束 | 说明 |
|------|------|------|
| D1 | 多源订阅 | 一个源 = 一个链接，自动识别 Gist / 普通 URL，订阅者零 GitHub 配置 |
| D2 | 文件前缀 | 订阅规则文件名加 `<sourceId>__` 前缀，删除源时按前缀清理 |
| D3 | 自动更新 | WorkManager 周期任务，约束 = 有网络，替代已删除的前台服务 |
| D4 | 排程控制 | `SubscriptionScheduler.reschedule()` 由"开关 + 间隔"驱动 |
| D5 | 使用量 | Gist 源 = 被动读评论数；URL 源 = 0；不做逐条累加 |

### 2.6 UI 约束

| 编号 | 约束 | 说明 |
|------|------|------|
| U1 | 主题色 | 深青绿 #007070 调色板，徽章色提供深色变体 |
| U2 | APP 名称 | strings.xml / SettingsScreen / MainActivity / HomeScreen 统一为"小狐" |
| U3 | 无障碍服务标签 | strings.xml 中为"小狐 - 广告自动跳过" |
| U4 | 图标 | 狐狸吉祥物设计，深青绿背景 #007070 |
| U5 | 深色模式 | 使用 `isSystemInDarkTheme()` 切换亮/暗徽章色 |
| U6 | 输入框 | 使用本地 `mutableStateOf` 作为唯一数据源，避免 Flow 异步回写导致光标跳开头 |
| U7 | 同步反馈 | loading 动画 + Toast；无订阅源跳转设置页并展开订阅卡片 + 蓝色引导横幅 |
| U8 | 内置规则 | 按合集分组，支持整组 Switch 批量启用/禁用 + 单条 Switch |
| U9 | 日志页 | 刷新按钮（2s 自动刷新 + ON_RESUME）、清除按钮（确认对话框）、历史文件列表 |

### 2.7 权限约束

| 权限 | 用途 |
|------|------|
| INTERNET | 订阅规则网络请求 |
| ACCESS_NETWORK_STATE | 网络状态检测 |
| QUERY_ALL_PACKAGES | 读取应用列表（白名单 + 内置规则过滤，OPPO 需手动授权） |
| FOREGROUND_SERVICE / FOREGROUND_SERVICE_SPECIAL_USE | 服务保活 / 订阅更新 |
| FOREGROUND_SERVICE_MEDIA_PROJECTION | 截图 OCR |
| POST_NOTIFICATIONS | 跳过通知 |
| BIND_ACCESSIBILITY_SERVICE | 无障碍服务（系统权限） |

### 2.8 测试约束

| 编号 | 约束 | 说明 |
|------|------|------|
| T1 | 单元测试 | 覆盖 RuleEngine 节流、RuleMatcher 匹配、RuleRepository 三源合并、TokenCipher、SubscriptionUrls |
| T2 | Instrumented 测试 | RuleEngine（节流/重置/多次标记/协程）、SkipHistoryStore（记录/清空/计数/7天/倒序）、WhitelistStore（增删改查/缓存同步） |
| T3 | CI | push/PR 触发，JDK 17，Gradle 缓存，assembleDebug + 单元测试，APK artifact 上传 |
| T4 | 真机测试 | 冷启动验证（force-stop → 亮屏 → 启动），避免热启动/息屏/频次耗尽导致的假阴性 |

### 2.9 设备兼容性约束

| 编号 | 约束 | 说明 |
|------|------|------|
| C1 | OPPO 服务检测 | `getEnabledAccessibilityServiceList` 在 OPPO 上不可靠，改用 `Settings.Secure.ENABLED_ACCESSIBILITY_SERVICES` 字符串检测 |
| C2 | OPPO 应用列表 | 需声明 `QUERY_ALL_PACKAGES`，提示用户手动到"设置 → 应用管理 → 小狐 → 权限管理 → 读取应用列表"授权 |
| C3 | 无障碍配置 | `accessibility_service_config.xml` 省略 `packageNames`（监听全部），声明 `canTakeScreenshot="true"` |
| C4 | settingsActivity | 配置中 `settingsActivity` 指向 `MainActivity`（非已删除的 SettingsActivity） |

## 四、变更控制

- 修改规则模板场景/优先级/节流值 → 需同步更新本文件 §2.3 和开发文档
- 新增/删除权限 → 需同步更新本文件 §2.7 和 AndroidManifest
- 修改主题色 → 需同步更新本文件 §2.6 和 `ui/theme/` 调色板
- 修改无障碍配置 → 需同步更新本文件 §2.4 和 `accessibility_service_config.xml`
