# 小狐规则共享教程（GitHub Gist）

> 适用版本：v1.0+ | 更新日期：2026-09-16
>
> 一句话总结：**作者上传规则到 Gist，把 Gist 链接发给别人；订阅者粘贴链接即可，不需要任何 GitHub 账号或 Token。**

---

## 一、先分清两个角色

| 角色 | 做什么 | 需要什么 |
|------|--------|----------|
| **作者**（分享规则的人） | 创建规则 → 上传到 GitHub Gist → 把 Gist 链接发给订阅者 | GitHub 账号 + Token（仅 gist 权限） |
| **订阅者**（使用规则的人） | 粘贴 Gist 链接 → 自动同步规则 | **什么都不需要**，粘贴链接即可 |

> **重要澄清：Token 绝对不能公开！**
> Token 相当于你 GitHub 账号的钥匙（拥有 gist 权限），公开等于把账号送人。
> 需要公开/分享的是 **Gist 链接**（形如 `https://gist.github.com/你的用户名/一串32位字符`），
> 订阅者拿这个链接就能匿名拉取规则，全程不需要 Token。

---

## 二、作者侧：上传规则到 Gist（共 4 步）

### 第 1 步：创建 GitHub Token（只需做一次）

1. 打开 [github.com](https://github.com) 并登录（没有账号先免费注册一个）。
2. 点右上角头像 → **Settings（设置）**。
3. 左侧菜单拉到最底部 → **Developer settings（开发者设置）**。
4. **Personal access tokens → Tokens (classic)** → 右上角 **Generate new token → Generate new token (classic)**。
5. 填写：
   - **Note**：随便写个名字，如 `xiaohu-share`。
   - **Expiration**：选有效期（建议 No expiration 或 90 天）。
   - **Select scopes**：**只勾选 `gist` 这一项**（不要勾 repo 等其他权限，权限越小越安全）。
6. 点底部绿色按钮 **Generate token**。
7. **立即复制生成的 Token**（`ghp_` 开头的一串字符）——**这个页面关掉后就再也看不到了**，务必保存好。

### 第 2 步：在 APP 里填入 Token（只需做一次）

1. 打开小狐 → **设置**。
2. 展开 **贡献者** 卡片。
3. 在 **GitHub Token** 输入框粘贴刚才的 Token（输入时会打码，正常）。
4. Token 在手机上使用 Android Keystore + AES-GCM 加密存储，不会明文落盘、不会上传。

### 第 3 步：创建你的规则库（本地规则）

1. 小狐 → **规则** → **本地** Tab。
2. 点右下角 **+** 新建规则，填写规则内容后**保存**。
3. 重复创建你想分享的多条规则——这些本地规则就是你的"规则库"。

### 第 4 步：上传到 Gist 并分享

1. 在规则编辑页点 **上传**（保存按钮旁）。
2. 首次上传会**自动创建一个 Gist**（公开可见，描述为 "LTT_GKD shared rules"），之后的规则会追加到同一个 Gist。
3. 上传成功后，你的 Gist ID 已自动保存在「设置 → 贡献者」里。
4. 打开 `https://gist.github.com/你的用户名` 找到这个 Gist，复制浏览器地址栏链接。
5. **把这个链接发给订阅者**（微信/QQ 随意）。

> 提示：Token 只在你自己的手机里；Gist 链接才是对外分享的东西。

---

## 三、订阅者侧：订阅规则（3 步，零配置）

1. 拿到作者发的 Gist 链接（或那串 32 位字符的 Gist ID）。
2. 小狐 → **规则** → **订阅** Tab → 右下角 **+**。
3. 粘贴链接 → 点 **添加并同步**。
4. 完成。之后作者更新规则，你在订阅页点 **全部同步** 或等自动更新即可。

---

## 四、常见问题

**Q1：订阅者需要 Token 吗？**
不需要。订阅是匿名读取公开 Gist，粘贴链接就行。这也是"订阅者零 GitHub 配置"的设计原则。

**Q2：我的规则别人能看到我是谁吗？**
Gist 会显示你的 GitHub 用户名。规则内部还带设备 ID 作为作者标识，用于去重保护（同 ID 规则只保留第一个创建者的版本）。

**Q3：上传失败提示"未配置 GitHub Token"？**
回到「设置 → 贡献者」检查 Token 是否已粘贴、是否完整（`ghp_` 开头，无多余空格）。

**Q4：订阅同步失败？**
检查链接是否完整（含 32 位 Gist ID）、手机网络是否可用；作者侧确认 Gist 仍是公开状态。

**Q5：我想换一个 GitHub 账号分享？**
直接换新 Token 填入即可；旧 Gist 里的规则仍在，新上传会创建新 Gist。

---

## 五、安全红线（再强调一遍）

1. **Token 永远不公开、不截图、不发群**。
2. Token 权限只勾 `gist`，不勾其他。
3. 不用了就去 GitHub 的 Tokens 页面 **Delete/Revoke** 掉。
4. 怀疑泄露：立即在 GitHub 上 Revoke 旧 Token，再生成新的填入 APP。
