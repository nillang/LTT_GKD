设计理念与说明

设计哲学

  • 李跳跳启发：首页一屏可见核心状态，三秒理解应用功能，降低认知负担
  • GKD启发：Material Design 3 风格，底部导航栏，结构化信息展示
  • 融合：极简首页 + 结构化深层页面，兼顾易用与功能完整
  • 2×2 Action Grid 替代纯文字列表，视觉层次更清晰

页面结构

  • 首页：状态卡片 + 统计卡片 + 快捷操作 + 最近记录 + 底部导航
  • 规则管理：三Tab（本地/订阅/内置）+ 规则卡片列表 + FAB
  • 规则编辑：模板选择 + 分组表单 + 匹配/动作 Chip + 底部保存栏
  • 应用列表：搜索框 + 三态筛选 + 白名单 Switch 行
  • 日志：双Tab（实时/历史）+ 彩色级别 + 工具栏
  • 设置：分组卡片 + 图标前缀 + 安全提示

安全与隐私

  • Gist Token 使用 Android Keystore + AES-GCM 加密存储
  • 设置页安全提示使用浅色背景卡片，显眼但不干扰
  • 服务描述强调"仅在本地运行，不上传任何用户数据"
  • 白名单应用不执行跳过操作，保护系统应用

交互细节

  • 状态卡片：绿色脉冲动画表示运行中，灰色静止表示停止
  • 底部导航：选中项顶部有指示条，图标和文字同时变色
  • 规则列表：Switch 开关直接在卡片上操作，无需进入编辑
  • 模板选择：选中态高亮 + 边框变色，预填推荐参数
  • 日志：按级别着色（E红/W橙/I蓝），等宽字体增强可读性

深色模式适配

  • 配色方案基于 Material Design 3 Tonal Palette
  • 深色模式下 Surface 切换为 #191C1B，Primary 保持 #00696D
  • 状态卡片在深色模式下使用更深的渐变
  • 日志级别颜色在深色模式下增强亮度保证对比度

规则模板系统

  • 5种预定义模板：开屏/插屏/Banner/激励视频/通用兜底
  • 每种模板预设优先级、节流时间和关键词
  • 新建规则时一键选择模板，自动填充表单
  • 模板卡片显示推荐参数摘要，帮助用户快速决策
