设计说明

设计哲学

  • 极简首页：只有状态卡 + 跳过统计 + 开启按钮，三秒上手
  • 李跳跳启发：新建规则极简 — 选模板 → 填包名 → 填文字 → 保存
  • GKD启发：订阅Tab支持URL、自动更新、同步，规则合集展示
  • 底部导航精简为3项：首页 / 规则 / 设置

页面结构

  • 首页：状态卡 + 累计跳过(查看/重置) + 开启服务按钮
  • 跳过记录：点击"查看"进入，按时间倒序展示跳过历史
  • 规则-本地：规则列表 + 上传共享按钮 + FAB新建
  • 规则-订阅：订阅源配置 + 同步按钮 + 合集列表
  • 新建规则：模板选择 + 名称/包名 + 匹配文字 + 动作 + 高级折叠
  • 设置：基础设置 + 规则订阅 + 贡献者 + 关于

优化点

  • 日志合并入设置 — 基础设置中"日志"项既是开关也是入口
  • 共享规则更名为"贡献者"，归入规则订阅分组
  • 新建规则隐藏高级选项 — 默认折叠，降低认知负担
  • 订阅Tab — 合集展示规则数、作者、订阅数，GKD风格
  • 跳过记录 — 新增页面，让用户直观看到"跳过了什么"

安全与隐私

  • 贡献者 Token 使用 Android Keystore + AES-GCM 加密
  • 安全提示用浅绿色卡片，显眼但不过度
  • 关于页强调"仅本地运行，不上传数据"
  • 白名单应用不执行跳过操作
