设计说明

首页设计

  • 服务按钮居中显示 — 大圆形，运行时高亮+脉冲光环
  • 不显示"运行中"文字 — 按钮颜色本身就是状态指示
  • 累计跳过小字显示在按钮下方 — 不抢视觉焦点
  • 查看/重置按钮跟随跳过计数 — 小巧不突兀
  • 关闭状态：灰色圆圈+0计数 — 一眼看出未开启

规则管理

  • 本地Tab：上传 + 导入 + 导出 三按钮横排
  • "上传"简化命名（原"上传共享"→"上传"）
  • 导入：从文件导入本地规则
  • 导出：导出所有本地规则为文件
  • 订阅Tab：自动订阅 + 手动同步 两个独立区块
  • 自动：开关+URL+间隔+保存按钮
  • 手动：立即同步按钮+删除已下载按钮

新建规则

  • 李跳跳风格：极简弹窗式表单
  • 两个下划线输入框：定位文字 + 关闭文字
  • 返回键关闭 — 单选按钮
  • 三个按钮：算了 / 举例(5) / 新增
  • 上方保留快速选择模板（5种）
  • 高级选项默认折叠 — 包名/优先级/节流等
  • "举例(5)"提供5个示例帮用户理解格式

其他优化

  • 跳过记录 — 纯计数页面，大数字+今日/本周/本月
  • 无跳过详情列表 — 保持简洁，只看数字
  • 设置精简为基础设置 + 贡献者 + 关于
  • 日志合并为基础设置中一项 — 开关+入口一体
  • 共享规则更名为"贡献者" — 更直白的命名
  • 规则订阅功能放在规则管理-订阅Tab内
