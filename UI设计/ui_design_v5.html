设计说明

品牌形象

  • 产品名称：XH（小狐）
  • 动漫形象：Q版chibi狐娘，黑发+青绿狐耳
  • App图标：狐娘内嵌于青绿色圆形中，人物偏下
  • 身体侧身回眸，双手自然下垂
  • 主色：#007070（青绿色）
  • 风格：扁平cel-shading动画风

首页

  • 顶部app-bar显示小狐图标+名称
  • 服务按钮完全居中（水平+垂直）
  • 跳过记录在偏下位置，与服务按钮有间距
  • 运行中：实心青绿圆+脉冲光环
  • 关闭态：灰色空心圆

规则管理

  • Tab改为动漫风格：带图标+加粗+3px底线
  • 右上角三点菜单：导入+导出
  • 操作栏：上传+新增按钮
  • 订阅Tab重新设计：订阅源下拉框+规则列表
  • 作者=自己 → "★ 我的"标记
  • 订阅Tab：保存按钮旁边是手动获取（带小字标签）

新建规则

  • 步骤式卡片设计（区别于李跳跳弹窗）
  • Step1 选择类型 → Step2 基本信息 → Step3 匹配动作
  • 每步带编号圆圈+标题+描述
  • 高级选项折叠

设置

  • 三组：基础设置 / 贡献者 / 关于
  • 基础设置：无障碍服务开关、OCR兜底开关、日志点击框
  • 日志改为点击框（无 ">" 箭头）
  • 移除跳过通知、移除规则订阅（订阅管理在规则管理→订阅Tab）
  • 贡献者：设备ID + GitHub Token + Gist ID + 安全提示
  • 关于：小狐图标 + 版本信息
